1 · ПОДКЛЮЧЕНИЕ YOUTUBE
Здесь вводятся только данные, необходимые streamPRO. Ничего угадывать не нужно.
HTTPS → backend
01 · API KeyGoogle Cloud → YouTube Data API → API key. Нужен для чтения чата.
02 · Live Video IDСкопируй ID текущей трансляции из ссылки YouTube. Например: abc123.
03 · Stream KeyYouTube Studio → Трансляция → ключ трансляции. Это пароль для отправки видео.
Дополнительно: OAuth access token
Для обычного чтения публичного live-чата streamPRO использует API key. OAuth оставлен отдельно, чтобы не путать обязательное и дополнительное.
Заполни три обязательных поля: Studio Token, API Key и Stream Key. Video ID нужен для автоматического подключения чата.
