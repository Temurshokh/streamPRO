5 · ШПАРГАЛКА
Реально нужны только эти данные.
1
Код доступа к Studio

Render → Environment → создай STUDIO_TOKEN и придумай для него свой пароль.

2
YouTube Live URL

Скопируй ссылку своей текущей трансляции из адресной строки браузера и вставь целиком.

3
Stream Key

YouTube Studio → Трансляция → ключ трансляции. Этот ключ никому не показывай.

4
API Key — только для чата

Не нужен, чтобы просто стримить. Нужен, когда включаешь режим «чат → игра». Если Google Cloud сейчас недоступен — этот пункт пропускаем.

Никогда не коммить секреты в GitHub. streamPRO отправляет их backend'у по HTTPS, а backend не возвращает значения секретов в публичный интерфейс.
